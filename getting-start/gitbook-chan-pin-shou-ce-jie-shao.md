# Gitbook 產品手冊介紹

### 什麼是 Gitbook 產品手冊？

Gitbook 產品手冊為 PaGamO 內部人員的產品知識查詢處，可以查閱以下內容：

1. 主要遊戲功能介紹
2. 主要遊戲功能設置
3. 各介面概覽
4. 各權限概覽
5. 各介面功能操作流程
6. 各介面功能名詞解釋
7. 答題數據計算方式
8. 道具與地形種類

{% hint style="info" %}
1) Gitbook 閱讀者可參考[此指南](gitbook-chan-pin-shou-ce-yue-du-zhe-zhi-nan.md)進行閱讀
2) Gitbook 撰寫者可參考[此指南](gitbook-chan-pin-shou-ce-zhuan-xie-zhe-zhi-nan.md)並以[此處的模板](wen-jian-mu-ban/)進行撰寫
{% endhint %}

### Gitbook 產品手冊的架構為何？

Gitbook 產品手冊主要分為五個區塊

1. Getting Start：可初步認識 Gitbook 與其閱讀、撰寫方式。
2. 使用情境：類似於 Help Center 的目錄，以使用者、使用情境做分類。閱讀者可進行資訊的查找。
3. 綜合資訊：內含各介面、權限、功能的介紹與數據的計算方式。閱讀者會透過使用情境的連結進入此區塊並閱讀這些資訊。
4. 功能操作：內涵各介面可執行的操作。閱讀者會透過使用情境的連結進入此區塊並閱讀這些資訊。
5. 團隊支援：當通過上述內容未獲得相關或肯定資訊時，可進一步獲取更多團隊支援的方式。
