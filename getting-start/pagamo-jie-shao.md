# PaGamO 介紹

### 遊戲主軸：打造專屬島嶼 <a href="#jie-shao" id="jie-shao"></a>

玩家可以打造自己的島嶼，而島嶼由一個個小正六邊形所組成；可以攻佔野地或他人的領土，擴張領土，也可以將佔領的土地蓋上各種地形，裝飾島嶼。

### 自由的答題機制

玩家可以選擇教師或是官方所派發的任務進行答題；也可以自由選擇想要練習的章節範圍，進行答題。而題目的類型則有五種類型：

* 選擇題：為單選題或多選題，題目最多會提供八個選項
* 是非題：選項僅有是與否兩個選項
* 閱讀題組：閱讀完長文後，根據文章內容作答，題目為為單選題或多選題，題目最多會提供八個選項
* 填充題：根據問題的前後文填入簡短答案
* 申論題：根據問題內容填入長篇論述

### 符合 108 課綱要求的素養教材 <a href="#jie-shao" id="jie-shao"></a>

除了自選題庫與任務書的內容可供孩子們進行答題與學習外，PaGamO 也有推出素養教材的商品，讓孩子們能夠培養圖表與長文解讀、培養閱讀習慣與理解力、補充課內外的領域知識。依照孩子們的需求，在遊戲化的遊戲介面，抑或是單獨答題的素養學習中心內進行答題。

### 特殊遊戲機制 <a href="#jie-shao" id="jie-shao"></a>

除了需要與攻擊機制搭配使用的任務書、自選章節外，還有魔物章節、學科挑戰、交易市集、每日獎勵、競賽之盾、奪寶信號與鍛造之錘等。

1. 任務書：分為「一般任務」、「世界任務」、「素養任務」三種。
2. 自選章節：玩家可以在這裡選擇自己想答題的題庫
3. 魔物指針：玩家們能夠一同答題與魔物戰鬥，攻擊敵方所造成血量可以變成積分，並獲取魔幣，而玩家們可以透過魔幣可以買到一些平常不能拿到的地形。
4. 學科挑戰：玩家須消耗「挑戰券」答題，系統會根據答對的題數決定玩家的星幣數，星幣可用以購買原本屬於素養品學堂的各種東西。另外，每月都有 3 張免費挑戰卷。
5. 交易市集：玩家之間的交易，可用其他玩家出的價格來購買各種道具、地形，而玩家也能上架自己想要出售的東西。
6. 每日獎勵：每天登入可以拿到一個獎勵，將以大富翁方式決定它是怪獸、道具、地形還是材料；而每月登入達 7、14、21、28 天，可以拿到另外一份獎勵。且一個月換一次不同的獎勵。
7. 競賽之盾：玩家們需要一起互相競爭，透過答題取得土地，換取更高的積分，系統會根據答對的題數、土地數量決定玩家的名次，並取得名次獎勵
8. 奪寶信號：與競賽之盾相同，不過其玩法更多元，玩家們需要攻佔高積分的寶藏。系統同樣地會根據答對的題數、土地數量決定玩家的名次，並取得名次獎勵
9. 鍛造之鎚：可以用背包裡的材料做出便宜於市價的道具或者平時難以取得的地形
10. 寵物系統：可於畫面點擊小夥伴兩次，並從對話裡獲得遊戲操作資訊
11. 好友系統：可以寄送禮物、能量給好友，也可與好友進行對話
