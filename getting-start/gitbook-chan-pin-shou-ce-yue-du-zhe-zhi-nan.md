# Gitbook 產品手冊閱讀者指南

### 查找功能的「介紹」

與查找功能操作方式相同，建議先使用 Gitbook 的搜尋功能（⌘+K），若沒搜尋結果頁並沒有你想要查詢的資訊，建議使用以下方式：

1. 先判斷該操作行為是隸屬於哪一種使用者的操作範圍，並跳轉至不同的名詞解釋頁
   1. [名詞解釋 - 主要遊戲功能](../shi-yong-qing-jing/hou-tai-shi-yong-qing-jing/gong-neng-yu-ji-zhi-jie-shao-zhu-yao-you-xi-gong-neng.md)
   2. [名詞解釋 - 玩家](../shi-yong-qing-jing/wan-jia-shi-yong-qing-jing/ming-ci-jie-shi-wan-jia.md)
   3. [名詞解釋 - 家長](../shi-yong-qing-jing/jia-chang-shi-yong-qing-jing/ming-ci-jie-shi-jia-chang.md)
   4. [名詞解釋 - 教師](../shi-yong-qing-jing/jiao-shi-shi-yong-qing-jing/ming-ci-jie-shi-jiao-shi.md)
   5. [名詞解釋 - 後台](../shi-yong-qing-jing/hou-tai-shi-yong-qing-jing/gong-neng-yu-ji-zhi-jie-shao-hou-tai.md)
2. 在分頁內尋找各功能的介紹超連結
3. 點擊介紹超連結，跳轉至詳細說明頁

### 查找功能的「操作方式」與「操作位置」

可先使用 Gitbook 的搜尋功能（⌘+K），搜尋此文件內包含該關鍵字的頁面，不過因為 Gitbook 的搜尋功能無法一次性地呈現所有搜尋結果，倘若搜尋結果頁並沒有你想要查詢的資訊，建議使用以下方式：

1. 先判斷該操作行為是隸屬於哪一種使用者的操作範圍
   * [玩家使用情境](../shi-yong-qing-jing/wan-jia-shi-yong-qing-jing/)
   * [家長使用情境](../shi-yong-qing-jing/jia-chang-shi-yong-qing-jing/)
   * [教師使用情境](../shi-yong-qing-jing/jiao-shi-shi-yong-qing-jing/)
   * [後台使用情境](../shi-yong-qing-jing/hou-tai-shi-yong-qing-jing/)
2. 判斷此操作行為會屬於哪一些操作分類項目，前往該分頁
3. 點擊分頁內的操作超連結，跳轉至詳細操作方式

{% hint style="info" %}
於操作分類項目的分頁中都會有「名詞解釋」的區塊，如果想瞭解功能的說明、數據計算方式，可以點擊此區塊下的各說明超連結，跳轉至詳細說明頁
{% endhint %}

### 遇到困難？

如果有資訊錯誤的問題，請使用 Slack 的資訊錯誤回報表單，將相關資訊提供給 PM team 的成員，並由 PM 值周生協助維護 Gitbook。

如果有資訊缺漏的問題，請使用 Slack 的資訊缺漏回報表單，將相關資訊提供給 PM team 的成員，並由 PM 值周生判斷該資訊是否需要納入 Gitbook 資訊範圍，如有其必要性，則將資訊加入 Gitbook。

{% hint style="info" %}
Slack 的回報表單位於側邊欄的「更多」 > 「自動化」 > 「所有工作流程」
{% endhint %}
