# 縣市 Open ID

### 縣市 Open ID 是什麼？

縣市 Open ID 是其中一種讓師生能夠以單一帳號登入有跟 OpenID 介接的網站的方式。

縣市 Open ID 保留了師生的各項資料，當用戶想要以 Open ID 的帳號使用某平台時，縣市 Open ID 會匯入相關資訊給該平台，如學生的班級資訊；教師的人事資訊等。

### 縣市 Open ID 與教育雲的關係為何？

教育雲可以視為 Open ID 介接的其中一個平台，用戶可透過該平台使用其他軟體 e.g. PaGamO、均一、學習吧、因材網等。而教育雲的資訊是從縣市 Open ID 而來，因此，用戶資料並非保留在教育雲中，而是繼續維持在縣市 Open ID。

縣市 Open ID 可能會因為轉校而無法繼續使用（因為資訊會留在原縣市主機，不會傳遞到另一縣市的主機），而教育雲不會因為轉校而無法使用，可終身使用；修改密碼時，縣市 Open ID 必須要透過學校人事或是網管重設；而教育雲帳號則需要登入「縣市 OpenID」後重設。
