# 分享作業

### 分享作業是什麼？

分享作業為此課程世界內教師互相分享作業的集中處，分為兩大區塊，分別是：

1. 教師分享：此課程世界內的其他教師所分享的作業
2. 我的分享：我分享給此課程世界內的其他教師的作業

同一個世界內的教師可以互相分享、引用作業，節省彼此額外出題的時間成本。

{% hint style="info" %}
為了保持一定的彈性，引用他人作業的教師可於自己的作業清單裡進行編輯，對引用作業進行題目的增刪，但無法修改題目內容，所做的變更也不會影響到原分享人的作業。
{% endhint %}

### 分享作業的機制為何？

1. 當同個世界的多個教師需要使用自己的題庫作為作業的出題來源即可分享該作業給其他教師
2. 分享的作業會標註該作業的分享人，而分享人隨時可以在作業清單裡取消分享
3. 引用者在分享作業裡選定想引用的作業後，該作業就會出現在自己的作業清單裡，引用者可以對引用作業進行題目的增刪，但無法修改題目內容，所做的變更也不會影響到原分享人的作業
