# 班級

### 班級是什麼？

班級為教師或是 PaGamO 營運派發作業與任務、檢視任務完成情形的基礎，教師需要透過班級派發班級作業、而遊戲內的班級可能會與真實世界的學生組成不同（課後輔導班等）；PaGamO 營運需要透過班級派發訂閱制素養教材。

### 班級清單的顯示規則為何？ <a href="#ru-he-xin-zeng-ban-ji-zuo-wei" id="ru-he-xin-zeng-ban-ji-zuo-wei"></a>

班級清單裡僅會顯示以下班級

1. 教師個人創建的班級
2. 後台創建且指定某一教師進入該班級

{% hint style="warning" %}
倘若沒有出現自己在教學上所負責管理的班級，可能是因為師生帳號管理介面裡並無設定完成，請參考[該連結](../../../gong-neng-cao-zuo/shi-sheng-zhang-hao-guan-li-jie-mian/ban-ji-guan-li/#ru-he-ti-yi-jian-li-hao-de-ban-ji-xin-zeng-huo-yi-chu-jiao-shi)
{% endhint %}

### 班級的排序規則為何？

班級會依照是否具備年級 Folder 進行排序規則的判別

1. 有年級 folder：年級排序 > 手動排序（帳號管理介面） > 創建時間排序（舊到新）
2. 沒有年級 folder：手動排序（帳號管理介面） > 創建時間排序
