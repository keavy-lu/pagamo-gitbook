# 學科挑戰介紹

### 學科挑戰是什麼遊戲模式？

學科挑戰是一種特別的<mark style="color:red;">跨課程</mark>答題模式，在任何世界進入學科挑戰塔，都是進入同一個挑戰塔，而裡面的關卡與挑戰進度都是一樣的，因此，這也代表挑戰券的數量也是共用的。玩家需要花費挑戰券進入挑戰塔中的不同關卡回答問題，在學科塔裡可以選擇國小/國中的任何年級段教材，同科目會有三座塔（例如國小英語、國中英語、國中英文會考），隨著關卡階層逐漸上升，答題難度也會隨之加深。

完成學科挑戰塔的關卡後，可以獲得星等（星星幣），而星等可在[星星商店裡購買商品](xue-ke-tiao-zhan-jie-shao.md#ru-he-wu-xing-xing-shang-dian-gou-mai-shang-pin)。在星星商店購買道具時需選擇使用課程，購買後會存在該課程背包。

{% hint style="info" %}
1. 每月會有三張挑戰券的免費額度，且會先優先消耗免費挑戰券\
   （每月的 1 日 00:00，系統會自動發送 3 張免費挑戰券到帳號上）
2. 免費的三張挑戰券若沒用掉，下個月會歸零，購買的券則會保留並累積
{% endhint %}

{% hint style="info" %}
挑戰舊關卡若獲得比前幾次還要多的星等，可以獲得多出的星等
{% endhint %}

{% hint style="info" %}
高中職世界並無學科挑戰塔
{% endhint %}

### &#x20;學科挑戰的遊戲進行機制為何？

* 進入挑戰塔的關卡並不會消耗體力
* 一座塔只有一個科目，點擊進入後可看到目前該塔的統計：關卡挑戰數、完美攻克數、獲取星星數
* 關卡會從第一關開始，超過一星過關即出現下一關可選擇，無法自行跳關選擇
* 已經挑戰過的關卡，會標示出挑戰結果：失敗、一星、二星、三星（重複挑戰會保留最佳成績）
* 若挑戰關卡到一半，中途關閉視窗，再回到學科挑戰塔介面、點擊該挑戰塔，會出現未做完的關卡與原來的題目，必須從第一題開始做。（重整頁面也保留原來的題目）
* 不受自選章節答過題目不能再出題的影響，所有題目都可以重複出現
* 每次挑戰新關卡都需要花費一張挑戰券；挑戰舊關卡並不會消耗挑戰券

{% hint style="info" %}
- 答對數 / 答題數 >= 90%，三星
- 答對數 / 答題數 >= 70%，二星
- 答對數 / 答題數 >= 50%，一星
- 答對數 / 答題數 < 50%，失敗
{% endhint %}

### 星星商店是什麼？

星星商店類似於[商店](../ming-ci-jie-shi/wan-jia/shang-dian.md#shang-dian-shi-shen-me)，可供購買道具。而玩家僅能使用參與學科挑戰塔所獲得的星等於星星商店中購買道具。
