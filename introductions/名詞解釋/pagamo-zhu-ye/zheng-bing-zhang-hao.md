# 整併帳號

### 整併帳號的機制為何？

如新帳號是透過**批量創建**所建立，而舊帳號為**一般帳號**，則適用以下規則：

大原則為保留舊帳號，並將新帳號的資訊匯入舊帳號，而新帳號的資訊則會刪除。

1. 同一課程世界內只有其中一個帳號有創建 GC，則保留該 GC 的資料
   * 若該 GC 隸屬於新帳號 > 將該 GC 資料匯入舊帳號中
   * 若該 GC 隸屬於舊帳號 > 將該 GC 資料繼續維持在舊帳號中
2. 同一課程世界內，新舊帳號皆有創建 GC > <mark style="color:red;">**不能合併**</mark>

如新帳號為**教育雲帳號**，而舊帳號為**批量創建帳號**，則適用以下規則：

大原則為保留新帳號，並將舊帳號的資訊匯入新帳號。

1. 舊帳號經合併後，原本世界 GC 只剩一塊地、角色一致、等級變成1、其他項目全清空，到期日改為合併日-1天」（使用者無法登入）
2. 新帳號經合併後，則
   1. 領土：舊帳號的總領土皆轉換為土地券，加入新帳號的背包中
   2. 地形：舊帳號的所有蓋好地形皆轉換成地形卡（含升級前的地形），加入新帳號的背包中
   3. 背包：舊帳號的所有道具數量加到新帳號中
   4. 金錢＆魔幣：舊帳號的數量加總至新帳號中
   5. 等級＆鍛造等級：舊帳號的總經驗值累加到新帳號，轉換為提升的等級
   6. 付費挑戰券（跨課程）：舊帳號的數量加總至新帳號中
   7. 星星幣（跨課程）：舊帳號的數量加到新帳號中
