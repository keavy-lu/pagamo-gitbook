# 訊息

### 訊息是什麼？

訊息的來源有三種，分別是官方、教師與其他玩家，而官方訊息又可以分為公告訊息與帳號訊息

1. 公告訊息： PaGamO 於單一世界發布的訊息
2. 班級訊息：教師於指定班級所發放的班級訊息​
3. 個人訊息：可檢視系統或好友所發送的訊息，閱讀完後也可選擇刪除訊息​
4. 帳號訊息：若用戶完成素養任務，即可從此處領取 素養品學堂 的完成獎勵（用戶僅能於系統設定的指定遊戲世界裡領取任務獎勵），閱讀完後也可選擇刪除訊息

{% hint style="info" %}
個人訊息的來源：

1. 被他人使用道具攻擊
2. 被他人打到重生
3. 其他角色傳送的訊息
4. 送禮物/收到禮物
5. 教師後台發送給個人的訊息（會顯示發送訊息的老師名字）
6. 後台發送道具頁發送道具時附加的訊息
7. 錯題回報後官方已處理通知
{% endhint %}
