# 土地金錢生產倍率

## PaGamO 金錢產生機制

### 一、金錢產量計算 (money\_production)

#### 基礎計算公式

```
每日金錢產量 = (所有土地的基礎血量總和) / 50
附註：基礎血量為土地起始血量（等級一的土地血量）
```

#### 常見地形血量表

| 地形 | 基礎血量 | 每塊每日產量 |
| -- | ---- | ------ |
| 草地 | 100  | 2      |
| 森林 | 200  | 4      |

#### 產量加成機制

| 加成類型 | 說明                            | 範例        |
| ---- | ----------------------------- | --------- |
| 角色加成 | 依角色特性提供金錢產量加成                 | Mia 1.2 倍 |
| 課程加成 | 課程可設定「土地金錢生產倍率 (天)」           | 2 倍       |
| 新手加成 | 創角後 X 天內 3 倍金錢產量（以 GC 建立時間起算） |           |

#### 更新金錢產量的時機

* 土地被奪取
* 土地被搶走
* 使用地形卡改變地形

### 二、不會產生金錢的條件

| 條件       | 是否產生金錢 | 備註           |
| -------- | ------ | ------------ |
| 假期模式     | ❌      |              |
| 課程鎖定     | ❌      | 鎖定期間金錢會暫停產生  |
| 未選角色     | ❌      |              |
| 無土地      | ❌      |              |
| 產生金錢 < 1 | ❌      | 累積到超過 1 才會更新 |

#### 結算產生的金錢的時機

1. 買賣道具（商店/交易市集）
2. 土地所有權異動(佔領土地 / 土地被他人佔領)
3. 前台（地圖）每 60 秒會透過 refresh API 取得「結算後的金錢量」與「金錢產量」

* 註: 不會真的更新金錢，只是拿現有資料換算出更新後的錢給使用者參考

### 三、範例說明

#### 範例一：基礎產錢

```
土地配置：
- 3 塊草地 (100 × 3 = 300)
- 2 塊森林 (200 × 2 = 400)

計算過程：
1. 基礎血量總和 = 700
2. 每日產量 = 700 / 50 = 14
3. 經過 6 小時可得：14 × (6/24) = 3.5 金錢
```

#### 範例二：新手期加成

```
條件：
- 同上述土地配置
- 創角第 5 天
- 間隔 12 小時

計算過程：
1. 基礎每日產量 = 14
2. 新手期 3 倍 = 42
3. 可得金錢 = 42 × (12/24) = 21
```

#### 範例三：多重加成

```
條件：
- 同上述土地配置
- 課程 2 倍加成
- 角色 1.5 倍加成
- 間隔 1 天

計算過程：
1. 基礎每日產量 = 14
2. 實際產量 = 14 × 2 × 1.5 = 42
3. 可得金錢 = 42 × 1 = 42
```

{% hint style="info" %}
若玩家仍在[新手保護期](../wan-jia/xin-shou-bao-hu-qi.md#xin-shou-bao-hu-qi-shi-shen-me)內，則其每日金錢產量為以 3 倍計算
{% endhint %}

{% hint style="info" %}
如選擇具備土地金錢生產加成的遊戲角色，其獲得的金錢量會另外加成指定的倍數
{% endhint %}
