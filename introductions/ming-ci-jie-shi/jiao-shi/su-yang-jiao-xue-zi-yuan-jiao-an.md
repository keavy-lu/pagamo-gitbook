# 素養教學資源（教案）

### 素養教學資源是什麼？

素養教學資源為官方的素養教案集中處，讓教師更容易獲取官方的素養教案，可瀏覽各個素養教案詳細資訊，並決定下載哪個檔案。此外，素養數據的班級作答狀況也會連結至此處，若從作答狀況判斷需要引導學生閱讀該篇文章，可連結至此處，並下載教案內的檔案。

### 素養教學資源有提供什麼檔案？

1. 導讀時可使用的簡報：提供教學新點子、培養學生思考力
2. 供教師派發紙本功課的學習單：培養學生從讀寫到完整表達的能力
3. 教師版本的學習單
4. 合作學習觀察表

{% hint style="info" %}
提供的檔案類型依據不同教案會有所不同
{% endhint %}

{% hint style="info" %}
素養任務有分成初中高階三種階等，而教師能夠看到三種素養任務，不會因為班級所在年級就只能看到一種階等的任務
{% endhint %}
