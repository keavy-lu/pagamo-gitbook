# 題目分類架構

### 題目分類架構是什麼？

題目分類架構類似於新增作業時所勾選的 Filter，供教師在瀏覽自己的題目時能夠順從分類架構，更方便檢視特定範圍的題目，同時也可以更方便將個人題庫裡的題目作為出題來源，出題給學生。而題目分類架構目前有分為三種層次：科目、冊次、章節：

1. 科目：國文、數學、社會科學、自然科學、音樂等不同科目
2. 冊次：國文高中第一冊、國文高中第二冊等不同冊次
3. 章節：第一冊第一章、第一冊第二章等

{% hint style="warning" %}
雖然章節之下還可以依序建立更小的子章節，\
但是在創建作業、選擇題目時，目前的功能並不支援選擇子章節
{% endhint %}
