# 重生功能

### 重生功能是什麼？

若用戶不滿意當前位置，如：發展空間不足、附近玩家有敵意時，可以啟動重生，既可移動至隨機位置，但會失去現有領土（不會將土地兌換成土地券與地形道具）。

{% hint style="info" %}
重生後五天內無法再次使用傳送道具和假期模式
{% endhint %}



### 系統判斷出生點/重生點的邏輯

1. 一般地圖、大亂鬥電競：
   1. 擴張的時機：有人要出生在地圖上，但經過 50 次還找不到合適的出生點時
   2. 擴張的大小：邊界擴大 5 圈
2. 電競（同心圓出生）:
   1. 擴張的時機：有人要出生在地圖上，但經過 3 次還找不到合適的出生點時
   2. 擴張的大小：邊界擴大 8 圈
3. 競賽之盾：
   1. 擴張的時機：有人要出生在地圖上，但經過 3 次還找不到合適的出生點時
   2. 擴張的大小：邊界擴大 5 圈
4. 自訂地圖（地編畫的)：不會擴張
