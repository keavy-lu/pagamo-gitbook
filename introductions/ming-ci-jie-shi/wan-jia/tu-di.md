# 土地

### 野地、領土有何區別？ <a href="#ban-ji-shi-shen-me" id="ban-ji-shi-shen-me"></a>

野地為沒有人佔領的土地，領土則是有人佔領的土地，無論是野地還是他人的領土，都可以透過前進（攻擊）攻佔。而野地有四種不同類型，分別為海洋、漂流木、深海野地、深海巨獸，後面三者是玩家透過道具所產生的特殊野地，可以防禦他人攻陷自己的領地。

{% hint style="info" %}
1. 土地等級有四種等級：基礎、一星、二星、三星，基礎地形有草原、荒沙、密林，一星地形除了基礎地形外，還有雪地、黃金、櫻花、楓葉等地形；若需要分辨地形星等，可以查看地形對應到的地形道具的道具圖上的星等數量
2. 每次訓練土地會升級，基礎～二星地形升滿五級就可以往上建造以升星等，三星地形最高只有一級
{% endhint %}

### 領土生產金錢的計算方式為何？

土地金錢為每分鐘更新一次，因此土地的增減會對金錢的生產量有所影響，而每一種土地所生成的金錢量每天可以產生 \[ 起始血量/50 ] Pa幣（起始血量是指該地形一等級時的血量）：一階土地一天約 2 元；二階土地 4～6 元，三階土地約 10\~15 元，四階土地約 30\~47 元，黃金雕像一天約生產 60 元。

{% hint style="info" %}
若玩家仍在[新手保護期](xin-shou-bao-hu-qi.md#xin-shou-bao-hu-qi-shi-shen-me)內，則其每日金錢產量為以 3 倍計算
{% endhint %}
