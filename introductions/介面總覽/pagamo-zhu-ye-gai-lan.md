# PaGamO 主頁概覽

<figure><img src="../../.gitbook/assets/截圖 2023-12-05 15.35.16.png" alt=""><figcaption></figcaption></figure>

**登入入口**

主頁為所有 PaGamO 用戶（包括玩家、教師、家長與管理者）的登入入口

1. 玩家、教師、管理者可以藉由 Header 的「登入/註冊」處進行登入
2. 家長需要先點擊任一素養學習商品介紹頁後，才能夠找到家長後台的登入入口（素養學習後台）

**課程入口**

設有快捷課程入口與課程列表，可供玩家、教師、管理者進入某課程世界。在快捷課程入口處，也可以選擇進入上一次進入的課程世界的不同介面（遊戲介面、素養學習中心、教師後台）

**Banner**

設有輪播圖檔與新聞資訊

1. 輪播圖檔的版面較大，位於快捷課程入口的上方，至多可上架八則圖檔，圖檔可設置超連結，用戶點擊後可跳轉至其他網頁
2. 新聞資訊的版面較小，位於快捷課程入口的下方，至多可上架四篇新聞，用戶點擊後新聞，主頁會跳出詳細新聞內容的視窗

**商品資訊**

設有素養商品與心願雜貨店的購買入口。

1. 點擊 Header 的素養學習，並選擇任一商品類別，即可跳轉至該類別的素養商品介紹頁與購買入口
2. 點擊 Header 的心願雜貨店，並選擇任一商品類別，即可跳轉至心願雜貨店中該類別的商品列表

**PaGamO 介紹**

設有 PaGamO 的各介紹頁與幫助中心，用戶可從幫助中心獲得遊戲介面、教師介面的功能資訊，帳號、付費的相關資訊。

**帳號資訊**

登入後，即可在原有  Header 的「登入/註冊」處查看帳號資訊，包括：參與的課程與比賽、素養商品的學習數據、個人設定（變更個人資訊、第三方綁定、更改密碼等）、消費紀錄。
