# 家長後台概覽

<figure><img src="../../.gitbook/assets/截圖 2024-01-02 11.05.28.png" alt=""><figcaption></figcaption></figure>

家長後台共分為 2 大區塊：**側邊功能選單**、**Header**

**側邊功能選單**

側邊的功能選單內的功能為家長後台的主要功能，包括

1. 個人設定：可更動個人資訊、密碼與付款方式
2. 教材管理：可檢視購買過的教材與其購買紀錄，也可重新訂閱之前取消訂閱的教材
3. 學習狀況：可檢視教材的綁定狀況
4. 訂單記錄：可檢視教材的購買紀錄
5. 我的獎勵：可使用月費折抵卷於訂閱制商品，也可檢視過去的折抵券使用紀錄
6. 登出

**Header**

用戶能於 Header&#x20;

1. 點擊「綁定LINE OA 的 CTA」綁定 LINE OA
2. 點擊「購買教材的 CTA」前往教材介紹頁
3. 點擊「幫助中心」前往主頁的幫助中心
4. 點擊「學習入口」前往主頁
5. 點擊個人頭像進一步使用邀請好友的功能、查看邀請好友的紀錄
